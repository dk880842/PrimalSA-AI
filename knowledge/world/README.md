## 座標系
- 地圖格子座標 (x, y)，原點左上；畫面是斜角（x 往右上、y 往右下）。
- 通行格：data/maps.bin，格子值 0=無地面 1=可通行 2=不可通行地面(水/懸崖) 3=物件阻擋。
- 方向（DirEnum）：0 下、1 左下、2 左、3 左上、4 上、5 右上、6 右、7 右下。
- NPC 常站在櫃檯後方，走到 NPC 3 格內即可對話。
