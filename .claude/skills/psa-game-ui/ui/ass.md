# 外掛 ASS（Automatic Synchronized System，遊戲內建）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「外掛」1300,760。ESC 關閉。
遊戲官方功能，不算違規外掛；**開來看可以，任何勾選、下拉、數值、SET 都要先問使用者**。主畫面「遇敵」1365,660 同理。
- 左上：選角色（DKB0…，黑點 = 選取中）。
- 左欄：戰鬥設定（原地遇敵、自動逃跑、快速戰鬥、自動戰鬥、夥伴助戰）、隱藏設定（隱藏名字、隱藏玩家、全部遮罩）、音量。
- 右欄頂端核取：戰鬥設置 / 便捷功能。
- 分頁：戰鬥設置 **696,206** / 一般設置 **850,212** / 捉寵設置 **984,212**。
  - 戰鬥設置：人物、戰寵的「首次動作 / 一般動作」＋對象；自動補血（精靈補血、寵物技能，人物 / 寵物 / 騎寵 % 門檻）。
  - 一般設置：鎖定騎寵、鎖定戰寵、自動轉換戰寵、自動吃智慧果和豆子、自動使用離線水晶、精靈補血、物品補氣。
  - 捉寵設置：自動抓寵、自動存倉庫、可抓捕數、目標系別 / 寵物、抓捕條件（血>=）、丟棄不滿足條件的寵物（攻< 防< 敏<）。
- 數值欄輸入方式**未實測**：推測是點欄位 → `key` 打數字 → 按旁邊的 SET，第一次做時要截圖確認。
- 遇敵（31207/90000000260）：原地遇敵，開啟後自動遇敵練等；提示文字建議搭配自動戰鬥。
