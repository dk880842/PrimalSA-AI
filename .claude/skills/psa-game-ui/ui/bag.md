> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面「背包」1120,760。**ESC 一次就關掉整個背包**（不管停在哪個分頁）。
- 左欄：角色頭像 DKB0 83,195 / DKB02 83,322 / DKB03 83,450 / DKB04 83,580 / DKB05 約 83,700。點了黃框移過去，**穿戴 / 卸下就作用在那個角色**（2026-10-09 實測），不用到切換面板改「當前」角色；「當前登錄」紅標不會動。多角色處理背包一律用這個。
- **多視窗（第 3b 步）**：左欄頭像是「名單第 1～5 個」的位置，`PSA_CLIENT=PrimalSA2` 時依序 DKBO6～DKBO10（同寵物面板 `petmatch.AVATAR_Y`）；`bag.py ... all` = 該視窗名單。
- 中間：裝備格＋HP/MP/攻防敏/屬性。
- 右側：道具格 5×4（第一格 752,236）。點道具 → 道具浮窗（名稱、類別、詳細介紹、**使用 / 丟棄**）；ESC 關閉。
- 下方：顯示道具名、刪除管理（**紅區**；批次刪用 `bag.py purge`，見下方「刪除管理腳本」）、整理背包。
- 右側分頁：背包 1318,265 / 倉庫 **1318,467**（個人 / 公共、擴容、倉庫頁；操作見下方「倉庫」）/ 圖鑑 **1318,668**（材料圖鑑合成：合成斧頭類、棍棒類…；配方見 `knowledge/crafting/`）。
- 「丟棄」是紅區（不可逆）。

## 道具辨識以名字為主：名字樣板 `itemname_match.py`（2026-10-14；只有離線測試，實機未驗）
- **為什麼**：縮圖（下一節）只認得到 imageId，大多數道具同圖多名（巴巴洛的許可證那張圖 109 個名字、風的鎖 8 個）；格名稱 OCR 會讀錯 / 漏字。
  「顯示道具名」開著時每格上半是白字名字（深色描邊，可能兩行：「巴巴洛的許 / 可證」「火的羽毛飾 / 品[火]」），固定渲染 → 整名圖樣板比對最確定。
- **順序（bag.py `icon_read`，find / find_items / team_read / list / item_slots / find_item 共用）**：一次截圖 → 空格（像素）→
  ① 名字樣板認得的格 = 確定名稱（`by: name`，不是 ambiguous）→ ② 名字沒認出的格才比縮圖（`by: icon`）→ ③ 還是沒認出 / 被蓋住的格才名稱 OCR（`by: ocr`）。
  名字樣板已認出是**別的**道具的格，find_item 的後備路徑（圖示樣板 / 格名 OCR / 逐格彈窗）也不再開。
  **動作類（use / store / take / drop / purge）照舊開彈窗 / 提示窗核對名稱**（名字樣板只決定先開哪一格；離線測試：名字樣板認出的格彈窗名稱不符 → 96、不按使用）。
- `PSA_ITEM_MATCH`：`auto`（預設，名字 → 縮圖 → OCR）| `name`（只用名字樣板，不比縮圖、不 OCR）| `iconocr`（2026-10-14 前的 auto：縮圖 → OCR，不看也不學名字樣板）| `icon`（只縮圖）| `ocr`（最舊：每格 OCR）。
- **比法**：名字區（背包格心 (−52,−44) 104×52 = `bag.SLOT_NAME_R`；倉庫格心 (−47,−42) 94×48）白字（三通道最小 > 200）二值化 →
  與樣板 IoU（±2 px 平移，`namematch.iou`）→ 最佳 ≥ 0.85 且贏次佳別的名稱 ≥ 0.15 才認，否則 None（不猜）。名字第二行疊到圖示上半，圖示上的白點也進樣板（同一道具一樣固定）；數量字在框外。
  背包 / 倉庫兩本樣板（格寬不同、換行不同）；倉庫頁右半是背包格（同座標同渲染，用背包那本）。
- **同名換一欄點陣就不一樣**：截圖是客戶區縮半，各欄格心的半像素相位不同 → 同欄同名 IoU = 1.000、換一欄只剩 0.65～0.9（不同名最高 0.731）。
  所以**每欄各學一個變體**（同名最多 8 個變體：5 欄 + 選取框 / 新道具紅標），跨欄不硬認（判不出 → 縮圖 / OCR，核對後學會那一欄）。第 3 列格心比字高 2 px，靠 ±2 平移吸收。
- **被蓋住的格不判**：沿用縮圖那套遮擋偵測（`itemimg_match.cell_state`：背包格內緣壓暗 / 倉庫格間米色縫壓暗）→ 等 1.5 秒重拍、最多 2 次，仍蓋住 → OCR。
- **「顯示道具名」關著**：有道具的格白點 < 250（離線：名字關著最多 163 點 = 圖示本身白點；開著最少約 340 點）→ `noname`，整頁都是 → `names_hidden`；名字層什麼都不給，照縮圖 / OCR（OCR 需要時才照舊點開「顯示道具名」）。名字層不會自己去開名字。
- **學法（保守，`bag._learn_verified` / `_learn_ocr`）**：只在 ① 彈窗名稱核對過（find_item 的彈窗核對、use / take / store / drop 動作前的核對）② 格名稱 OCR 去重後**完全等於** Item 表名稱（「巴巴洛的許 可證」→ 巴巴洛的許可證；只讀到「巴巴洛的許」不學）時學。
