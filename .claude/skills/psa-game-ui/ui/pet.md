## 操作：設定出戰 / 騎乘（2026-10-09 實測）
1. 點左欄頭像選角色 → 點寵物格 → 點「出戰」或「騎乘」。立即生效，無確認框；寵物格紅標會變「戰鬥」/「騎乘」。
2. 部分寵物要先有**騎權**（學騎乘）才能騎：`knowledge/pets/ride.md` 的「需學習」=1 就要先到 NPC 學（NpcScript studyRideLevel）。
   例：瑪斯貝卡（需學習 0，可直接騎）、迪基格斯（需學習 1）。
3. 多角色一次跑完（每個角色的寵物排列要一樣，先截圖確認）：
```
bash tools/gui/gui.sh seq "click 83 <頭像Y>; wait 700; click 250 200; wait 400; click 390 702; wait 700; \
  click 250 322; wait 500; click 532 702; wait 900; shot"
```

- 想讓出戰 / 騎乘狀態固定不被改掉：外掛「一般設置」的鎖定騎寵 / 鎖定戰寵，見 [ass.md](ass.md)。

## 鎖定戰寵 = 外掛 ASS 的設定，會擋寵物面板（2026-10-10 實測）

- 換戰寵流程：外掛選角色 → 取消勾 656,377 → 寵物面板選角色頭像、點寵物格、「出戰」390,702 → 外掛選角色 → 下拉 1285,377 選寵物 → 重新勾 656,377。
  下拉項目 y：第 1 格 419、第 2 格 461、第 3 格 503、第 4 格 545（x 1050；順序 = 寵物欄順序，本帳號 迪基格斯 / 瑪斯貝卡 / 金布伊 / 摩娜西普）。

- 自動化：`tools/gui/petwatch.py`（監測金布伊等級，≥ 門檻換回迪基格斯，順便補血檢查與維持原地遇敵）。

## 寵物學技能（2026-10-10 實測）
範例：DKB0 的迪基格斯學「忠犬」（保護主人不受敵人的直接攻擊），花 3000 石幣（349,500 → 346,500；不花鑽石）。
1. 寵物面板（318,80）→ 左欄選角色、寵物欄選寵物 → 技能區 7 格座標：1 815,518 / 2 920,518 / 3 1024,518 / 4 1130,518 / 5 1235,518 / 6 813,620 / 7 918,620。空格是「+」，已學的右上標「主」。
2. 點空格（用第 3 格 1024,518）→「學習技能」視窗（兩欄列表，可往下捲）。列表（x 左欄 360 / 右欄 620）：攻擊 2000、防禦 2000、背水之戰1 2000 / 2 3000、連續攻擊 2000、三段攻擊 3000、破除防禦 3000、忠犬 3000（620,488）、突擊 3000、雙重突擊 5000、一擊必殺 3000、不防守戰法1 2000…；每列 y 約 200 / 290 / 380 / 470 / 560 / 650。
3. 點技能 → 右側顯示技能名、說明、價格（石幣圖示）；「學習」鈕 985,657。
4. 跳「提示」：「確定要讓【寵物名】學習【技能】嗎？」→ 確定 615,557 / 取消 813,557（提示右上 ✕ 946,208）。
5. 成功：頂部浮字「寵物X學習了技能Y，扣除石幣 3000」，技能格出現該技能。
- 關閉：學習技能視窗 ✕ 1213,108（寵物面板 ✕ 1310,108 在它右邊）；寵物面板 ✕ 1310,108。
- 面板頂部資源列：石幣 349,500（x 335,y 23）、鑽石、活力、聲望。
- 切角色（2026-10-10 實測）：寵物面板左欄頭像可直接切換，點一下即切（DKB0 82,210 / DKB02 82,340 / DKB03 82,470 / DKB04 82,599 / DKB05 82,695，第 5 個只露出一半但可點）；組隊中可用，面板內容（寵物、技能欄）跟著換，不用切換面板。5 人戰寵都是迪基格斯，學完忠犬後技能格 3 皆為忠犬。

## 腳本化 `pet.py`：像素 / 樣板判斷（P-I5 實測 2026-10-11）
指令見 SKILL.md「`pet.py list / set-state / rest-all`」；全部在 2880×1659、5 人隊掛機地圖（庫塔伊洞窟）量的；座標 = 截圖座標。每個角色目前只有 2 隻寵物：第 1 格 瑪斯貝卡（騎乘、128）、第 2 格 迪基格斯（出戰、130），第 3～5 格空。
- **選取**：點頭像 / 寵物格都只是選取，無副作用。**點空格不會改變選取**（畫面仍停在上一隻寵物，名字 / 等級是上一隻的）→ 一定要先判斷空格。
- **空格**：爪印底 4 點（x,y = 250,格心+2 / 250,格心−5 / 230,格心+15 / 270,格心−15）≈ (155,123,82) / (179,145,98) / (179,145,98) / (155,122,82)，容差 14；有寵物的格這 4 點是寵物圖，不會同時吻合。格心 = 200 / 322 / 445 / 567 / 690。
- **選中的格**：格子左邊框 (200, 格心−30)：選中 = 橘黃 (251,146,4)，沒選 ≈ (196,183,155)。
- **選中的頭像**：黃框上緣 (83, y)：DKBO 156 / DKBO2 285 / DKBO3 413 / DKBO4 542 / DKBO5 671（各 3 px 高；選中 ≈ (244,189,20)、沒選 ≈ (211,191,163)）。各頭像間距不一致（127 / 128 / 130 / 120），所以 y 不能用固定間距推。頭像下方名字（DKBO～DKBO4）可用咖啡色字樣板核對；第 5 個頭像的名字被面板切掉。
- **狀態鈕亮度**（亮 = 棕底；每顆看兩點，兩點都亮才算）：
  | 狀態 | 探針點 | 亮 | 不亮 |
  |---|---|---|---|
  | 出戰 | 345,702 / 440,702 | (182,124,60) / (182,114,51) | (252,224,191) / (245,224,192) |
  | 騎乘 | 487,702 / 580,702 | (186,129,64) / (187,125,60) | (245,223,191) |
  | 休息（= 等待） | 627,702 / 700,702 | (187,125,66) / (193,128,63)（set-state 往返實測） | (245,225,194) / (245,219,190) |
  剛好一顆亮 = 該狀態；其他 = 讀不準（None）。**休息亮時**：寵物格左上紅標變「等待」、主畫面左上寵物頭像變成「爪印 + 0」（沒有出戰寵）。
- **名字**：選中寵物名字框 430,160 200×45；字是奶油色 (≈240,224,128)、底是棕木牌。OCR：`-Dark 120 -Zooms 2,3`（舊作法）約一半讀成空字串或少字（「迪基格斯」→「迪基斯」）；**`-Dark 0 -Zooms 2,3,4`（不二值化直接放大）6/6 精確**。圖樣板更好：同名 IoU = 1.000（5 角色 × 同名寵物完全相同）、不同名 0.366 → `petmatch.py` 整塊圖樣板（`gui pixel` 讀 9000 點約 0.17 s）。
- **等級**：模型下方黃字「0轉N」框 470,620 130×36（OCR）。**OCR 很不穩**：「0轉128」常讀成 28 / 1、「0轉130」讀成 134 / 30（-Dark 70 / 90 / 120 各有各的錯法，只有 `-Dark 0` 與 `-Dark 50` 對 128 都讀對）；petwatch 以前單組 OCR 會把 128 讀成 28。樣板法：黃字（r>220、g>200、b<110）切成 0 / 車 / 專 / 數字，單字樣板由右往左收數字、遇到「專」（轉 右半）才算讀完，沒學過的字回 None。樣板是學出來的（OCR 三組設定共識才學）。
- **EXP 橫幅會蓋住名字框**（掛機中，x 450～1000、y 140～262）：樣板對不上時 pet.py 等 0.8 s 重讀（最多 2 次）；仍不行就名字 None、**不猜**。想要穩，用 `--pause-encounter`。
- **鎖定戰寵 / 戰鬥中**時點狀態鈕沒反應：pet.py 只點 1 次，讀回沒變就回 74，不自動去外掛解鎖。
- 樣板檔：`tools/.cache/pet-tpl/2880x1659.json`（name / avatar / digit；刪掉會重學）。
