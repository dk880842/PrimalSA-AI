# 人物資訊（roleinfo）

> 座標 = `gui.sh shot` 截圖座標（客戶區 2880×1659 → 截圖 1440×830）。索引見 [README.md](README.md)。

入口：主畫面頭像 119,68。ESC 關閉。
- 左欄：各角色頭像（DKB0…），點了切換正在看的角色；有黃框的是目前選取的。
- 中間：名字（可改名鈕）、裝扮、`0轉1級(角色ID)`、家族。
- 右側分頁：**基礎** 1381,320（預設）／**精靈** 1381,595（學過的精靈技能，沒學是空白）。
- 基礎頁：HP/MP、地水火風屬性條、屬性重置；攻擊/防禦/敏捷、石抗/睡抗/酒抗/毒抗/混抗/麻抗、抗性說明；潛力點與體力/腕力/耐力/速度、潛力重置；下方 6 格鎖（未解鎖欄位）。
- **確認補滿血用這頁**：HP / MP 條上直接寫「目前/上限」（例 551/551、100/100），比主畫面 HUD 只有目前值可靠。左欄頭像可直接切角色逐一看 5 人（2026-10-10 使用者指示）。戰寵 HP 上限要到寵物面板看。
- 屬性重置、潛力重置：會改角色，要使用者同意。

## EXP 條與讀經驗（exp.py，2026-10-12 實機）
- 面板最下方（不隨分頁變）EXP 條，文字「目前/本級所需」（例 58756681/69487425）在截圖座標約 x 660～860、y≈792；OCR 框 (560,778,400,28)，白字 `-Light 170`。中間「1轉128級(10001154)」框 (178,664,432,36)。
- 本級所需 = knowledge `Exp.jsonl` 該級的 exp（128 級 69,487,425 相符）；`exp.py` 以此交叉驗證 OCR，對不上整組 None。累積經驗 = Σ Exp[1..級-1] + 目前。
- 多 zoom OCR 會回多行，常夾錯字行（643763/…）：逐行 parse 後投票，不能把各行串起來再 regex。
- 左欄頭像與寵物面板同座標（`petmatch.AVATAR_Y`），黃框判斷共用 `pet.is_avatar_sel`。
- 面板特徵：✕ 1336,112 (197,73,49) + 標題條 730,100 / 660,100。紅區：屬性重置 1207,280、潛力重置 1207,718、改名 573,180、裝扮 395,627。
- 指令：`exp.py read --role all`（唯讀）、`exp.py eta --target 131 --interval 300`（讀兩次估速率）、`--from-history`（只讀一次配歷史）。
