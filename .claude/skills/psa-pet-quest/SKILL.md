# 交寵物任務（抓 → 分 → 練 → 交），以恐龍博士 2016 / 卡坦的願望 2019 為例

**REQUIRED BACKGROUND:** 先載入 psa-game-ui（工具、紅區、驗證視窗立刻停手）。會用到 `/psa-disband-team`、`/psa-quick-team`、`/psa-grind-start`；寵物面板細節見 `../psa-game-ui/ui/pet.md`、倉庫見 `ui/bag.md`、外掛見 `ui/ass.md`。
座標是截圖座標（客戶區 2880×1659）。`G="bash tools/gui/gui.sh"`，在專案根目錄執行。實測日 2026-10-10，隊伍 DKB0、DKB02～05（0 轉 128 級）。
**轉生或吃封印書後這些任務會重置，要整套重做**（先用 `psa.py` 查任務等級、寵物 ID 是否改變）。
寵物存取工具：`pet.py list / set-state / rest-all / store / take`（見 psa-game-ui SKILL.md；先用工具、非 0 才手動）。
**多人一律用批次版**（2026-10-12）：`pet.py store-many / take-many [--plan "DKBO2:克邦凱斯,DKBO3:#35/7/3/8,DKBO:朵拉比斯@126"] / set-state-many`、`bag.py store|take all 名稱 [--skip-missing]`、`pet_catch.py --lock / --autoswap`：面板只開一次、倉庫分頁 / 子分頁只切一次、左欄頭像換人連續做完再關（不要一人一次開關）；新抓的寵物沒名字（名字框是成長字串）見下方「轉生後寵物重整」。


## 何時用
- Task 步驟類型是交寵物（`psa.py steps <任務ID>` / `knowledge/quests/`：寵物 ID × 數量 + petLevel），或使用者說抓寵 / 練寵交任務。
- 條件：petLevel 是「≥」（實測 18 / 25 / 30 都過），交出的寵物會被收走（clean=1），寵物只是消耗品。**每個角色各要一套**。

## 前置
- **當前角色一律維持 DKB0**，不用切換面板換人。
- 寵物 / 道具 / 倉庫：開左上「寵物」或「道具」面板，用**面板左側頭像**切換角色（寵物面板 318,80；頭像 DKB0 82,210 / 02 82,340 / 03 82,470 / 04 82,599 / 05 82,695）。**先確認面板真的開了再點頭像**（否則會誤點左側任務追蹤）。
- 外掛（1300,760）用面板內角色欄選人。
- **只有逐人交任務時**才用切換面板（763,760 開）：卡片 DKB0 620,300 / DKB02 930,300 / DKB03 620,385 / DKB04 930,385 / DKB05 620,470（以 ui/team.md 為準）；換人後角色在原地；交完切回 DKB0。

## 四條核心規則
1. **從倉庫取出 / 抓到的寵物預設「等待」**：練寵前每人要把第一隻按「出戰」（390,703），其餘交給自動轉換戰寵。沒有出戰寵就拿不到經驗。
2. **交寵物任務前，所有任務寵都要改成「等待 / 休息」**：**先跑 `uv run --no-project python tools/gui/pet.py rest-all`**（`--dry-run` 先看會改哪些；5 人約 13～30 s；只把「出戰的非騎寵」改等待、騎寵一律不動；鎖定戰寵會回 74、戰鬥中 78，加 `--pause-encounter` 自動關遇敵；名字讀不出但縮圖認得物種〔img_species、非騎寵〕的出戰寵 2026-10-13 起照改等待，縮圖也認不出才 72）；questrun `--pet-turnin` 的 rest-all 失敗訊息會提示 72 / 74 原因、quest.py 29（寵物沒湊齊按完成循環）→ 117 並提示寵物沒湊齊；非 0 再手動（休息 672,702）：自動轉換戰寵會把後面的寵物換成出戰；卡坦曾因一隻鯊在出戰，按「完成」21 次都不前進。
3. **寵物存倉絕不選第一格騎寵（瑪斯貝卡 / 布拉奇多斯；`uikit.MOUNTS` 已加布拉奇多斯，朵拉比斯、迪基格斯、魯尼帖斯等不受影響）**：**先跑 `uv run --no-project python tools/gui/pet.py store DKBO 迪基格斯 --depot personal`**（腳本硬性擋：名字是 / 像瑪斯貝卡、狀態騎乘、第 1 格都 73 零倉庫點擊，要存第 1 格的非騎寵才加 `--allow-slot1`；點存入鈕前驗倉庫特徵 + 子分頁 + 縮圖簽名 + 按鈕底色 + 按鈕文字；每次最多點 1 次；存入出戰中的寵物會跳確認視窗，腳本驗文字後點確定；**掛機中（遇敵開）要加 `--pause-encounter`**，戰鬥中寵物操作會被吃掉）；**唯一例外 `--allow-mount-store <名字>`：只有使用者當次明講「存騎寵」才用**（2026-10-11 使用者授權存瑪斯貝卡 / 布拉奇多斯，不是常態授權，不得自行沿用）；只放行名字完全等於旗標值的騎寵（像但不同仍擋）、寵物必須已是「等待」（騎乘中仍 73，先 `set-state <角色> 瑪斯貝卡 等待 --allow-mount`）、第 1 格要同時帶 `--allow-slot1`，例：`store DKBO 瑪斯貝卡 --depot personal --allow-slot1 --allow-mount-store 瑪斯貝卡`；縮圖簽名 / 按鈕文字 / 確認視窗驗證照舊；非 0 才手動：按「存入寵物」前截圖確認選中名稱，依名字不依格位（曾兩次選中騎寵，一次真的存進去，要取回改騎乘）。
4. **寵物倉庫存入 / 取出用按鈕，不能點兩下**：存入 / 取出是**同一顆鈕 530,697**（選寵物 =「存入寵物」、選倉庫卡 =「取出寵物」；舊寫的取出 675,703 是錯的，那裡是白色方塊）。取出用 `pet.py take DKBO --depot personal --pet 迪基格斯`（現場逐張讀卡找；**一定要給目標**：`--pet` / `--expect-growth` / `--expect-level`，`--index N` 只能配 `--expect-*`、取前讀該格核對，不符 72 不取；取出後再驗，不符 76，不自動存回，交人處理）。**只有道具倉庫才可點兩下**。

## 流程
### 0. 準備
- 外掛「一般設置」取消鎖定戰寵（656,377；先 pixel 確認是勾的才點）。
- **先跑 `pet.py store <角色> <寵物名> --depot personal`**（每人每隻一次，約 8 s；成功後印倉庫第幾格，後面格子往前補位、倉庫會重新排序）。手動退路：寵物面板 → 右側「倉庫」1365,440 →「個人」897,170 /「公共」1160,170。5 人寵物欄只留騎寵（瑪斯貝卡），其他寵物選格（250,200 / 322 / 445 / 567 / 690）→ 存入寵物 530,697（出戰中的寵物會跳確認視窗，點確定 615,557），存進**個人倉庫**（每次 1 秒內成功）。
- 公共誘餌：背包 → 倉庫 1318,467 → 公共 547,200，點格 237,292 → 浮窗「取出」732,648（整疊全取）。誘餌用完會自動取消勾選自動抓寵。

### 1. 抓（外掛「捉寵設置」984,212）
- **DKB0 不抓**（抓寵角色會被系統傳走）；由 DKB02～05 抓。非當前角色也能抓、會被系統送去抓，DKB0 畫面不變。
- 抓前：關原地遇敵、解散隊伍（`/psa-disband-team`）。
- 誘餌拆分：該角色背包點誘餌 860,352 → 浮窗「拆分」628,648 → 點數量欄 755,451 跳數字鍵盤 → 輸入 N → 確認 908,574 → 確定 610,545（取消 828,545 / X 950,205）。**N = 可抓捕數 = 要抓的隻數**。剩下的整疊存回公共：倉庫公共分頁下，背包格 dclick 966,352（道具倉庫可點兩下）。
- 外掛選角色（左上 298,151）→ 系別下拉 921,377（清單 8 項，用 drag 750,650→750,480 捲）→ 寵物下拉 1283,377 → 可抓捕數（1213,315）確認 = N → 勾「自動存倉庫」820,315 → 勾「自動抓寵」656,315。
- 約 1.5 分鐘抓完 2 隻（5 隻約數分鐘）；抓完遊戲自己取消「自動抓寵」，可抓捕數歸 0、誘餌歸 0；失敗不額外扣誘餌（誘餌數 = 隻數）。寵物進**寵物欄**（欄未滿時；滿了才進個人倉庫）。
- **抓寵角色的快速戰鬥會被遊戲關掉**，之後恢復掛機要逐人重查。
- 抓寵期間每 30 秒截圖，出現驗證視窗立刻停手。

### 2. 分（共用寵物倉庫 20 格；個人倉庫 20 格）
- 抓一種分一種：抓的人自己留 1 隻，其餘 `pet.py store <角色> <寵物名> --depot public` 存共用；其他人一行 `pet.py take-many --depot public --plan "DKBO2:克邦凱斯,DKBO3:加克拉"`（面板 / 公共子分頁只開一次、頭像換人；現場逐張讀卡找，取走後格子會遞補，每次都重讀，不沿用格號）。手動退路：存入寵物 530,697；取出 = 選倉庫格 → 同一顆鈕 530,697（變「取出寵物」）。逐人驗收：寵物欄 = 騎寵 + 任務寵（卡坦 4 隻剛好滿 5 格）。取出的寵物預設等待。
  （公共倉庫的 store / take 流程與個人倉庫相同，**尚未實機跑過公共**；第一次用請先 `--depot public` 單次驗證。）

### 3. 練（地點：柯奧4F龜洞 Lv80，練級傳送 → 柯奧山的小洞窟４樓 11004）
- 外掛左欄勾「自動轉換戰寵」（轉換級數使用者已設 30，所有任務寵統一練到 30；練完**取消勾選**）。
- 每人第一隻按「出戰」390,703（規則 1）。
- `/psa-quick-team` 組隊 → `/psa-grind-start`（原地遇敵 + 5 人快速戰鬥逐一確認）。
- 監測：寵物面板逐人點頭像讀寵物等級；全部達標才收。交前逐人確認每隻都在、等級都到（否則整隊「條件不滿足」）。
- 流程順序：先全部抓好 → 全部練好 → 再交。

### 4. 交
- 全部任務寵改「休息」（規則 2）：`pet.py rest-all`，非 0 才手動；跑完 `pet.py list --role all` 看每人狀態。
- **恐龍博士（2016，11006 博士的研究所）**：組隊 → 任務詳情支線「恐龍博士」傳送到研究所 → 接任務（哈魯 11,11）→ **隊長解散、逐人交**。吉魯 11,7「恐龍博士」→「完成」（步 1，魯尼帖斯 Lv18+）→ 跳「選擇」寵物視窗（兩張卡，順序每人不同，**看名字選**）→ 點卡片 → 確定 706,614；步 2 點任務追蹤 205,325 巡到哈魯 → 完成 → 選擇視窗（貝魯卡 Lv30+）→ 確定。每人 10 秒內，逐人用切換面板，交完切回 DKB0。
- **卡坦的願望（2019，薩伊那斯 100:230,180）**：**5 人組隊、隊長 DKB0 交一次，5 人同時完成**（步 1、步 2 都是）。交完逐人確認追蹤進步 2 / 寵物被收走。`quest.py --task 卡坦的願望` 可用，quest.py 偵測到同一 NPC 對話重複無進展會以退出碼 33 停手（2026-10-10 加入）。

### 4b. 恐龍博士逐人交的腳本（2026-10-12 起）
`uv run --no-project python tools/gui/pet_turnin.py dino DKBO DKBO2 DKBO3 DKBO4 DKBO5`（隊伍先解散；DKBO 是當前角色就帶 `--no-switch`；每人步 1、2 約 30 秒）：
`char.ensure` → 點追蹤「恐龍博士」→ 對話框左鈕 →「選擇」視窗 OCR 卡片名字、**依名字**點卡（卡片變黃底才按確定 706,614）→ 視窗消失。退出碼 120～125（檔頭）。
選擇視窗：標題「選擇」（-Dark 0 才讀得到）、卡片名字區 570,305 300×245（-Dark 150，兩個放大倍數會重複，y 差 ≤15 併成一張）、卡 y 約 341 / 446 / 544（第 3 張被截半，要捲）、點卡 x=700、y=名字行 +10。
接取：`questrun run 2016 --after none` 會接取並在步 1 停 115（2026-10-12 前步號讀不到會落到 quest.py 對話空轉 117，已修：全 manual 任務步號讀不到也當 manual）；questrun 2026-10-12 起預設**不吃**龍王的守護（要吃加 `--dragon`；`--no-dragon` 仍可用、= 預設）。
**自動交（`--pet-turnin`，離線測試過、未實機）**：`questrun run 2016 --after none --pet-turnin` → 步 1 / 2（manual）改成 `pet.py rest-all` → `team.disband` → `pet_turnin dino` 5 人逐人 → `char.ensure DKBO` → `team.form` → 讀詳情；失敗 150。第一次用建議先照上面手動跑 `pet_turnin.py` 驗過。

### 5. 獎勵處理
- **布克布克（恐龍）、修寶（卡坦步 1）可丟**：`uv run --no-project python tools/gui/petdrop.py all 布克布克 --confirm-name 布克布克`（2026-10-12 實機驗證 5 人；先 `--dry-run`）。手動：寵物面板選該格 → 垃圾桶 708,565 → 提示窗「確定要丟棄【名字】嗎?」**確認名稱** → 確定 615,557。**只限這兩種**，其他寵物一律不丟。
  **跟任務一起丟**：`questrun run 2016 --drop-reward 布克布克 --confirm-drop 布克布克`（全部任務成功後、恢復掛機前；只丟名字相同且 **1 級**的——練過的同名寵、等級讀不出都擋 73；失敗 151 不恢復掛機）；單獨用 `petdrop.py all 布克布克 --confirm-name 布克布克 --max-level 1`。
  提示窗名字在黃字括號裡：OCR 要 `-Dark 120` 才讀得到（`-Dark 0` 只讀到「回收站保存48小時!」）；`bag.name_match` 會把【…】內容刪掉不能用 → `petdrop.confirm_names_ok`。
- **朵拉比斯（卡坦步 2，另有綁定鑽石 5）**：存個人倉庫。

### 6. 收尾
- 取消「自動轉換戰寵」勾選；取回原寵物（迪基格斯等）、恢復出戰 / 騎寵（外掛鎖定戰寵 / 鎖定騎寵重勾，先確認騎寵還是瑪斯貝卡）。
- `/psa-grind-start` 恢復掛機（抓寵角色快速戰鬥被關，要逐人重查）。
- 寫 `notes/quest-log.md`（抓寵耗時、誘餌消耗、交任務有無挑寵物視窗、失誤）。

## 轉生後寵物重整（2026-10-11，腳本 `tools/gui/rebirth_pets.py`）
轉生後 5 人寵物欄清空重來：舊寵物全存個人倉庫 → DKBO2 外掛抓 5 隻騎寵（布拉奇多斯，系別「雷龍系」）→ 經公共倉庫分給其他 4 人 → 設騎乘 → 各自取朵拉比斯設出戰 → 外掛重新鎖定。手動版紀錄見 `notes/quest-log.md`「轉生後寵物重整」。
```
uv run --no-project python tools/gui/rebirth_pets.py --dry-run                       # 先看計畫（不碰遊戲）
uv run --no-project python tools/gui/rebirth_pets.py --trans 1 --store-mount 瑪斯貝卡   # --store-mount 只有使用者當次明講才加
uv run --no-project python tools/gui/rebirth_pets.py --from catch                    # 中斷後從某階段續跑（進度 tools/.cache/rebirth_pets.json）
```
階段與退出碼：preflight 100 / boxes 101 / store 102 / catch 103 / distribute 104 / ride 105 / battle 106 / lock 107 / cleanup 108 / 參數與進度不一致 109（全文見檔頭）。
- **實機驗證狀態：只有離線測試**（test_rebirth_pets.py + test_pet.py 新案例）。pet.py 舊的 store / take 實機驗證過；store-many / take-many / 沒名字寵物辨識 / learn-species、bag.py、外掛捉寵設置與鎖定的「讀字找列」都沒在遊戲上跑過。第一次實跑請在旁邊看，並先唯讀確認：`pet.py list`（沒名字的寵物顯示 `?(49/9/8/2)`）。
- **沒名字的新寵物**：名字框顯示成長字串，樣板 / Monster 表認不得。`pet.py learn-species DKBO 1 布拉奇多斯 --confirm-growth <該格字串>` 先登錄一次（縮圖簽名 + 字串；5 人現有騎寵是已知的布拉奇多斯，可以拿來學），之後用物種名 `--pet 布拉奇多斯` 找得到；同物種多隻要 `--pick first|last`。腳本抓寵時用「外掛只選了單一物種 + 試抓 1 隻剛好多 1 隻沒名字」三重確認才登錄，再抓 4 隻靠縮圖認。登錄檔沒有 = 不猜（72 / 73）。

## 外掛「鎖定戰寵 / 鎖定騎寵」下拉順序每人不同（2026-10-12 實測）
