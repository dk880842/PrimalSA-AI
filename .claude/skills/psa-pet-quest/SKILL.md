# 交寵物任務（抓 → 分 → 練 → 交），以恐龍博士 2016 / 卡坦的願望 2019 為例

**REQUIRED BACKGROUND:** 先載入 psa-game-ui（工具、紅區、驗證視窗立刻停手）。會用到 `/psa-disband-team`、`/psa-quick-team`、`/psa-grind-start`；寵物面板細節見 `../psa-game-ui/ui/pet.md`、倉庫見 `ui/bag.md`、外掛見 `ui/ass.md`。
座標是截圖座標（客戶區 2880×1659）。`G="bash tools/gui/gui.sh"`，在專案根目錄執行。實測日 2026-10-10，隊伍 DKB0、DKB02～05（0 轉 128 級）。
**轉生或吃封印書後這些任務會重置，要整套重做**（先用 `psa.py` 查任務等級、寵物 ID 是否改變）。
寵物存取工具：`pet.py list / set-state / rest-all / store / take`（見 psa-game-ui SKILL.md；先用工具、非 0 才手動）。
**多人一律用批次版**（2026-10-12）：`pet.py store-many / take-many [--plan "DKBO2:克邦凱斯,DKBO3:#35/7/3/8,DKBO:朵拉比斯@126"] / set-state-many`、`bag.py store|take all 名稱 [--skip-missing]`、`pet_catch.py --lock / --autoswap`：面板只開一次、倉庫分頁 / 子分頁只切一次、左欄頭像換人連續做完再關（不要一人一次開關）；新抓的寵物沒名字（名字框是成長字串）見下方「轉生後寵物重整」。


## 新寵物一律還原名字、辨識改名字為主（2026-10-14 晚，使用者實測、使用者定）
- 寵物面板名字框右邊鉛筆 →「修改名字」→ **輸入框留空按確認 = 名字變回物種名**（不扣費）。成長字串（a/b/c/d）的沒名字寵物一律還原，之後只靠名字認（不再靠 learn-species / 成長字串登錄檔 / 縮圖；那些退為備援）。
- `pet.py reset-name --role DKBO2,DKBO3`：寵物欄成長字串的全部還原（騎寵也可以，改名不改狀態）；`pet.py store / store-many` 存倉前也會自動先還原（`--no-rename` 關）；
  倉庫裡已經是成長字串的卡：`pet.py depot-fix-names --depot public,personal --role all`（取出 → 還原 → 存回原倉庫；寵物欄沒空格就跳過列出）。
- **流程腳本共用 `pet.reset_soft`**（2026-10-14 晚；離線測試，reset-name 本身實機驗過 8 隻布拉奇多斯）：讀到費用字樣 67 / 驗證視窗 9 / 斷線 10 → 原樣回、停手；其他失敗（66 鉛筆 / 視窗、70、78…）→ rc 0 + `soft_rc`，呼叫端記事件、**只有名字讀不出的那隻**走舊的成長字串登錄 / learn-species（備援），不卡住。
- **petquest（恐龍博士、卡坦）最簡流程（使用者 2026-10-16，離線測試）**：一次抓滿 `pet_catch --stages setup,wait`（**不再跑 rename / register**）→ `pet.py reset-name --role 抓寵者`（數字名全改回物種名；費用字樣 67 → petquest 165 停手、其他失敗也停）→ 馬上 `store-many --plan "角色:物種×在欄隻數,…" --depot public --pick last` 一次存公共（面板開一次、左欄頭像連續換人；已存完的人記 `stored_roles`，續跑只做剩下的）→ 個人倉庫溢出的 `take-many --depot personal --plan "角色:?"`（取沒名字的卡，不認物種）取回 + `reset-name`（抓寵者自己就有自己那種）→ 其他人 `take-many --depot public` 取缺的 → **只驗每人寵物欄格數 = 騎寵 + 本輪種類數**（恐龍 3、卡坦 5）。
  拿掉：catch-pre 快照、register 名字驗證 / 成長字串登錄備援、recount（depot-list 三處清點 / pre_store / 冪等重算）、distribute 的嚴格身分計數。`pet_catch --stages rename,register` 與 `pet.py depot-list` 工具仍在，只是 petquest 不再呼叫（手動補救用）。
  之後交寵物（pet_turnin「選擇」視窗依名字點卡）/ 丟獎勵寵（petdrop 名字完全相同）都以名字找；名字在 catch 的 reset-name 就已是物種名。
- **rebirth_pets（轉生後抓 1 級騎寵）**：catch 每批抓完 `reset_soft(catcher)`，名字 = 物種就過、不學物種；learn-species 只在還原失敗時做（試抓那隻三重確認 / 直接抓靠縮圖 ≥ 0.9）；費用字樣 → 103 停手。還原前的成長字串記進度檔 `data.growths`。distribute（take-many）/ ride（set-state）以名字找。
  lock：騎寵已有名字 → 外掛下拉比物種名 `('name', 布拉奇多斯)`，**下拉找不到物種名才退回成長字串**（growth / growth_partial，剛好一列才選）——**改名後外掛下拉是否顯示物種名是推測，待實機確認**；`pet_catch --lock` 同一套（讀 rebirth_pets 進度檔的成長字串）。
- 任何一步讀到「鑽石 / 石幣 / 費用…」→ 按取消、退出碼 67 停手；細節 / 座標 / 實測見 `../psa-game-ui/ui/pet.md`「還原名字 + 名字為主」。

## 讀寵物身分變快 / 變準（2026-10-14 petglyph）
- 成長字串（沒名字的新寵物）改用字形樣板讀（不 OCR，不會再把 40 讀成「姍」）；倉庫 `depot-list` 一次讀全部卡片上的白字 / 綠字，**不再逐張選卡**（掛機中選卡會被戰鬥結束刷新跳回寵物欄第 1 格 → 讀到別隻）；`take` 找卡先點卡片字像目標的那張（等級同時對上的優先）。細節 / 實測見 `../psa-game-ui/ui/pet.md`「字形樣板讀字」。
- 候選內縮圖決勝加第三關投票：卡坦倉庫卡 奇寶 / 克克洛斯（冠毛被字蓋住）不再 None。
- 種子字形缺「3」（名字框、卡片白字）與綠字「4 5 6」：第一次遇到走 OCR、讀到就學，之後就快。**實機存取（store / take）時仍要 `--pause-encounter`**。

## 總控腳本 `petquest.py`（2026-10-13，**只有離線測試，整支未實機**）
一行跑完一個寵物任務（接取 → 抓 / 分 / 練 → 交 → 丟獎勵寵 → 換回原戰寵），每段呼叫下面各節的既有腳本，失敗停在該段、印手動指令，進度檔 `tools/.cache/petquest.json` 續跑：
```
uv run --no-project python tools/gui/petquest.py plan 2016|2019|3003                     # 先看每段指令（不碰遊戲）
uv run --no-project python tools/gui/petquest.py run 2016 --confirm-drop   # 恐龍博士（誘餌不夠自動買「+」，不需旗標；--confirm-buy-bait 無作用）
uv run --no-project python tools/gui/petquest.py run 2019 --confirm-drop   # 卡坦的願望（鯊、雞兩輪）
uv run --no-project python tools/gui/petquest.py run 3003 --confirm-drop                        # 猜謎三兄弟（金布伊練 77）
  [--from 段] [--to 段] [--fresh] [--dry-run]
```
- **段（2026-10-15 使用者改順序：先存第 2 格、抓 / 練完才接任務）**：恐龍 `prep catch distribute train accept turnin drop restore`；卡坦 `prep catch1 distribute1 train1 accept turnin1 drop1 catch2 distribute2 train2 turnin2 store_reward restore`（第 2 輪雞要第 1 輪交完、步號 2 才能進）；猜謎 `accept step1 prep train turnin drop restore`（`plan` 印全文）。
- **prep（恐龍 / 卡坦，不先接任務）**：關遇敵 + 等戰鬥結束 → 解散（2026-10-16 精簡：不讀追蹤步號、不取消鎖定戰寵、不檢查空格數）→ 進度檔頂層有共用紀錄 `slot2_stored`（24 小時內，恐龍博士 prep 已存）→ 沿用、**不讀不存**（卡坦接恐龍博士就停在這）；沒有（單獨跑 / 恐龍博士）才：`pet.py list` 讀每人寵物欄**第 2 格**（`pet.py list` 的 `slot == 2`，slot 從 1 起算 = 面板由上往下第 2 張卡；第 1 格 = 騎寵位置，`guard_store` 預設不存）的寵物，名字 + 等級記進度檔 `battle` / `orig`（各角色可不同：p1 朵拉比斯、p2 迪基格斯〔瑪斯貝卡騎乘〕；不看出戰狀態；續跑沿用不重讀）。保險：任何人第 2 格空 / 名字讀不出（只有縮圖不算）/ 等級讀不到 / 是騎寵（騎乘中、名字像騎寵）→ 162 停手、一隻都不存 → 第 2 格的寵物存個人倉庫（同名一組 store-many；同名多隻 72 不猜）→ 寫 `slot2_stored`（`{qid, orig, battle, ts}`，restore 真正換回原寵成功才清）。accept 也不讀步號（2026-10-16 起；舊版讀到 2 跳過第 1 輪交 / 丟已拿掉）。以下 restore / 換回的「朵拉比斯」一律指各角色記下的第 2 格名字；只有卡坦獎勵寵固定是朵拉比斯（`REWARD_PET`）。猜謎 prep 照舊記當下出戰寵（petwatch `--back` 只收單一名字，各人不同時 160 停手）。
- **accept（恐龍 / 卡坦）**：第 1 輪 train 的 rest-all 之後才 `questrun.py run <ID> --after none`（115 / 155 / 117 照舊）；不讀追蹤步號；回 0 = 任務已完成 → 交 / 丟跳過，只做 restore（第 2 格照樣取回、出戰、鎖定；練好的任務寵留在寵物欄）。
- **catch（2026-10-16 最簡流程）**：**一次抓滿本輪總隻數 N（正常 5），不分批**：外掛捉寵設置已勾「自動存倉庫」，寵物欄滿了多抓的自動進抓寵者個人寵物倉庫（在欄 = min(N, 4)、其餘溢出；prep 後抓寵者空格固定 4〔騎寵 + 4 空〕，**抓前抓後都不讀寵物欄**；第 1 輪接在 prep 後**不重複 solo**，只有第 2 輪 / catch 單獨續跑才 solo〔關遇敵 + 解散〕）。小步記在進度檔 `sub_r<輪>.step`：`caught`（pet_catch bait → [誘餌不夠：**不需旗標**，現有的照用、外掛「+」只買缺額、不讀石幣、按前讀不到鑽石 163、每按一次可抓捕數必須 +1、鑽石有變停] → `setup,wait`；**不 baitback**：只取 / 買剛好 N，抓完不剩，使用者 2026-10-16） → `renamed`（`reset-name`）→ `stored`（一次 `store-many --plan 角色:物種×在欄隻數,… --depot public --pick last`；`stored_roles` 記已存的人）→ `taken_personal`（溢出的 `take-many --depot personal --plan 角色:?`（溢出那隻從沒改名、卡上是成長字串 → 取沒名字的卡，不認物種 / 不比縮圖；沒名字的卡多於溢出隻數 → pet 72 → 165 不猜；2026-10-16 卡坦 p2 舊版用物種名找 → 72） → `reset-name` 取回者 → 溢出 > 1 才把多的再 `store-many` 進公共，欄只留 1 隻自用）。溢出數 > 4 → 164 不抓；上次抓到一半（進度檔 `catch_started_<段>` 旗標有、沒 caught）→ 164 請人處理（不讀欄；整理後 `--fresh`）。
  - **中途失敗 / 續跑**：每個小步中斷後從下一小步接，**不重新盤點**（沒有 depot-list / recount）。`pet_catch` setup / wait 失敗 → 它自己把自動抓寵勾掉（`pet_catch.py --catch-off`），petquest 回 164；重跑時抓寵者寵物欄沒有任務寵（含數字名的）→ 從頭抓；已有任務寵 → 164 請人整理（不自動盤點倉庫）。`caught` 之後的失敗重跑直接從失敗的小步接（reset-name / store-many / take-many 各自可重入：`stored_roles` 只補沒存的人）。
  - **舊流程歷史（2026-10-14，petquest 已不呼叫，只對手動 `pet_catch --stages register` 適用）**：register 依「誰抓的」登錄成長字串、撞號 v2 登錄檔（`growth_src`）、register 不碰騎寵 / 抓寵前舊寵物（`catch-pre.json`）、每隻新寵物都要有交代（17）。細節見 `../psa-game-ui/ui/pet.md`「任務候選相對比較 + 主色」。
  - `rebirth_pets._split` 2026-10-13 改：整疊比要的少 → 按取消、回 92（bait_take 整疊存回公共）；舊版照輸入數量 → 拆分失敗 95。

- **train（2026-10-16 精簡）**：autoswap on（**整個任務只勾一次**：進度檔頂層 `autoswap_on`〔24 小時內〕已有就不跑；卡坦第 2 輪、恐龍博士帶 `--keep-autoswap` 接過來都不再勾）→ 第一種任務寵 `set-state-many` 出戰（本身已驗證，失敗就停；**已拿掉 `pet_catch --verify-battle`**）→ `grind.py start --spot 波拉島`（使用者 2026-10-15 指定恐龍博士 / 卡坦練寵固定 80 級練功區；舊版柯奧4F龜洞） → **每 10 秒讀等級**（`POLL_S`，45 分牆鐘總時限）：第一次 `pet.py list` 讀一次（只為知道任務寵在哪幾格、哪格是哪種；`task_slot_map`），之後只 `pet.py levels --slots <任務寵格>`（`levels_of`）；讀取失敗下一輪再讀（不改讀 list）；`TrainConfirm`：每隻（角色 + 物種）連兩次讀值 ≥ 門檻就鎖定，全部鎖定才算（恐龍 魯尼帖斯 18 / 貝魯卡 30、卡坦 25；最多 45 分）。**已拿掉**：名字框點陣 nh 比對與「點陣不同 → 改讀 list」、`TRAIN_MISREAD_UP` 誤讀判斷、`TRAIN_OVER` 超過門檻 +15 強制重讀、`merge_levels` / `task_levels`。→ 關遇敵 → `rest-all --candidates`（成功記進度檔 `rested`）→ **autoswap off 只在整個任務最後**：卡坦第 2 輪 train 結束、或恐龍博士沒帶 `--keep-autoswap` 的 train 結束；卡坦第 1 輪 / 帶 `--keep-autoswap` 不關。猜謎：`grind.py start`（去練功：依等級選點 + 未滿地雷區起 follow；petwatch 在跑時 follow 暫停）→ `petwatch.py --pet 金布伊 --level 77 --back 朵拉比斯 --exp-fruit`。
