# 交寵物任務（抓 → 分 → 練 → 交），以恐龍博士 2016 / 卡坦的願望 2019 為例

**REQUIRED BACKGROUND:** 先載入 psa-game-ui（工具、紅區、驗證視窗立刻停手）。會用到 `/psa-disband-team`、`/psa-quick-team`、`/psa-grind-start`；寵物面板細節見 `../psa-game-ui/ui/pet.md`、倉庫見 `ui/bag.md`、外掛見 `ui/ass.md`。
座標是截圖座標（客戶區 2880×1659）。`G="bash tools/gui/gui.sh"`，在專案根目錄執行。實測日 2026-10-10，隊伍 DKB0、DKB02～05（0 轉 128 級）。
**轉生或吃封印書後這些任務會重置，要整套重做**（先用 `psa.py` 查任務等級、寵物 ID 是否改變）。
寵物存取工具：`pet.py list / set-state / rest-all / store / take`（見 psa-game-ui SKILL.md；先用工具、非 0 才手動）。
**多人一律用批次版**（2026-10-12）：`pet.py store-many / take-many [--plan "DKBO2:克邦凱斯,DKBO3:#35/7/3/8,DKBO:朵拉比斯@126"] / set-state-many`、`bag.py store|take all 名稱 [--skip-missing]`、`pet_catch.py --lock / --autoswap`：面板只開一次、倉庫分頁 / 子分頁只切一次、左欄頭像換人連續做完再關（不要一人一次開關）；新抓的寵物沒名字（名字框是成長字串）見下方「轉生後寵物重整」。


## 總控腳本 `petquest.py`（2026-10-13，**只有離線測試，整支未實機**）
一行跑完一個寵物任務（接取 → 抓 / 分 / 練 → 交 → 丟獎勵寵 → 換回原戰寵），每段呼叫下面各節的既有腳本，失敗停在該段、印手動指令，進度檔 `tools/.cache/petquest.json` 續跑：
```
uv run --no-project python tools/gui/petquest.py plan 2016|2019|3003                     # 先看每段指令（不碰遊戲）
uv run --no-project python tools/gui/petquest.py run 2016 --confirm-drop [--confirm-buy-bait]   # 恐龍博士
uv run --no-project python tools/gui/petquest.py run 2019 --confirm-drop [--confirm-buy-bait]   # 卡坦的願望（鯊、雞兩輪）
uv run --no-project python tools/gui/petquest.py run 3003 --confirm-drop                        # 猜謎三兄弟（金布伊練 77）
  [--from 段] [--to 段] [--fresh] [--dry-run]
```

## 何時用
- Task 步驟類型是交寵物（`psa.py steps <任務ID>` / `knowledge/quests/`：寵物 ID × 數量 + petLevel），或使用者說抓寵 / 練寵交任務。
- 條件：petLevel 是「≥」（實測 18 / 25 / 30 都過），交出的寵物會被收走（clean=1），寵物只是消耗品。**每個角色各要一套**。

## 四條核心規則
1. **從倉庫取出 / 抓到的寵物預設「等待」**：練寵前每人要把第一隻按「出戰」（390,703），其餘交給自動轉換戰寵。沒有出戰寵就拿不到經驗。
2. **交寵物任務前，所有任務寵都要改成「等待 / 休息」**：**先跑 `uv run --no-project python tools/gui/pet.py rest-all`**（`--dry-run` 先看會改哪些；5 人約 13～30 s；只把「出戰的非騎寵」改等待、騎寵一律不動；鎖定戰寵會回 74、戰鬥中 78，加 `--pause-encounter` 自動關遇敵；名字讀不出但縮圖認得物種〔img_species、非騎寵〕的出戰寵 2026-10-13 起照改等待，縮圖也認不出才 72）；questrun `--pet-turnin` 的 rest-all 失敗訊息會提示 72 / 74 原因、quest.py 29（寵物沒湊齊按完成循環）→ 117 並提示寵物沒湊齊；非 0 再手動（休息 672,702）：自動轉換戰寵會把後面的寵物換成出戰；卡坦曾因一隻鯊在出戰，按「完成」21 次都不前進。
3. **寵物存倉絕不選第一格騎寵（瑪斯貝卡 / 布拉奇多斯；`uikit.MOUNTS` 已加布拉奇多斯，朵拉比斯、迪基格斯、魯尼帖斯等不受影響）**：**先跑 `uv run --no-project python tools/gui/pet.py store DKBO 迪基格斯 --depot personal`**（腳本硬性擋：名字是 / 像瑪斯貝卡、狀態騎乘、第 1 格都 73 零倉庫點擊，要存第 1 格的非騎寵才加 `--allow-slot1`；點存入鈕前驗倉庫特徵 + 子分頁 + 縮圖簽名 + 按鈕底色 + 按鈕文字；每次最多點 1 次；存入出戰中的寵物會跳確認視窗，腳本驗文字後點確定；**掛機中（遇敵開）要加 `--pause-encounter`**，戰鬥中寵物操作會被吃掉）；**唯一例外 `--allow-mount-store <名字>`：只有使用者當次明講「存騎寵」才用**（2026-10-11 使用者授權存瑪斯貝卡 / 布拉奇多斯，不是常態授權，不得自行沿用）；只放行名字完全等於旗標值的騎寵（像但不同仍擋）、寵物必須已是「等待」（騎乘中仍 73，先 `set-state <角色> 瑪斯貝卡 等待 --allow-mount`）、第 1 格要同時帶 `--allow-slot1`，例：`store DKBO 瑪斯貝卡 --depot personal --allow-slot1 --allow-mount-store 瑪斯貝卡`；縮圖簽名 / 按鈕文字 / 確認視窗驗證照舊；非 0 才手動：按「存入寵物」前截圖確認選中名稱，依名字不依格位（曾兩次選中騎寵，一次真的存進去，要取回改騎乘）。
4. **寵物倉庫存入 / 取出用按鈕，不能點兩下**：存入 / 取出是**同一顆鈕 530,697**（選寵物 =「存入寵物」、選倉庫卡 =「取出寵物」；舊寫的取出 675,703 是錯的，那裡是白色方塊）。取出用 `pet.py take DKBO --depot personal --pet 迪基格斯`（現場逐張讀卡找；**一定要給目標**：`--pet` / `--expect-growth` / `--expect-level`，`--index N` 只能配 `--expect-*`、取前讀該格核對，不符 72 不取；取出後再驗，不符 76，不自動存回，交人處理）。**只有道具倉庫才可點兩下**。

## 流程
### 0. 準備
- 外掛「一般設置」取消鎖定戰寵（656,377；先 pixel 確認是勾的才點）。
